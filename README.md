# student-skill-exchange-platform
java swing project for student skill exchange
Student Skill Exchange Platform

A Java Swing desktop application that helps students share their skills, discover other students and exchange knowledge.

Technologies Used

- Java
- Java Swing
- Java AWT
- File Handling
- Notepad / Java IDE

Features

1. Register students with personal and academic details.
2. Add skills that students can teach.
3. Add skills that students want to learn.
4. View all registered students and their skills.
5. Search students by name, department or skill.
6. Create skill-exchange requests.
7. View saved exchange requests.
8. Store student information using text files.
9. Validate user inputs.
10. Display exchange request status as Pending.

Project Structure

File / Folder| Purpose

data/| Stores application data

README.md| Project documentation
Project Report PDF| Complete project report

Modules

1. Register Student

Allows students to enter their name, email, department, year, skills to teach and skills to learn.

2. View Skills

Displays registered students and their skills in a table.

3. Find Students

Searches students using their name, department or skills.

4. Exchange Requests

Allows students to create and view skill-exchange requests.

How to Run

Make sure JDK 8 or higher is installed.

Compile the program:

javac StudentSkillExchange.java

Run the program:

java StudentSkillExchange

The application automatically creates a data folder to store student details and exchange requests.
